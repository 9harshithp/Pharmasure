## Overview

**PharmaSure** is an end-to-end pharmaceutical safety, predictive expiry alert, inventory tracking, and medication adherence ecosystem with integrated clinical AI. It combines a responsive React single-page application (PWA) with a Spring Boot REST backend connected to a MySQL database and Google Gemini multimodal reasoning engines.

## Data Flow

### 1. Vision OCR & Expiry Ingestion
```
User captures medicine image
       │
       ▼
Canvas Preprocessing (Bilinear scaling, Contrast normalization)
       │
       ├──► [Tier 1] Google Gemini Multimodal API (gemini-flash-latest)
       │        └─ Structured JSON extraction { name, expiryDate }
       │
       └──► [Tier 2 Fallback] Tesseract.js In-Browser OCR
                └─ Regex heuristics (EXP, B.NO, MM/YYYY extraction)
       │
       ▼
Auto-populates Medication Modal Form -> Validated & Saved to Backend
```

### 2. Patient Dose Tracking & Adherence
```
Patient marks dose as consumed (via QuickDose FAB or Table Action)
       │
       ▼
POST /consumed (saves dose timestamp, medicationId, patientId)
       │
       ▼
ConsumedChart & ConsumedCount re-fetch analytics
       │
       ▼
Adherence score computed & rings updated dynamically
```

### 3. Expiry Risk & Alert Workflow
```
Client calculates FEFO Days Remaining: (ExpiryDate - Today)
       │
       ├── Critical (< 30 days): Red indicator, immediate alarm banner
       ├── Warning (30 - 90 days): Amber indicator, WhatsApp pharmacy restock trigger
       └── Safe (> 90 days): Green indicator
```
